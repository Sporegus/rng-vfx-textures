# NOVA mouth layers v4

55 layers on a 3000 x 4000 transparent canvas. Character height 3400 px.

Mouths are extracted from the accepted nine-panel sheet, preserving their drawn angles. Original full-body neutral art and existing blink/smile layers are retained.

Talking: leave original art visible, hide Smile_mouth, show Talking_skin_patch and exactly one Mouth_ layer. Neutral: hide skin patch and all Mouth_ talking layers. Blink layers can be used independently. All optional layers are hidden initially.

This is a discrete mouth-state pack. Teeth and tongue are part of each sprite. Smooth mesh deformation, audio synchronization, hidden overlap completion and a native Cubism rig are not included. Source sheet and aligned face preview included.
